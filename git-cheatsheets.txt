
ШПАРГАЛКА ПО GIT — ИСЕНБЕКОВА ЭСМИРА, ГРУППА ИСП-241


1. НАСТРОЙКА И ИНИЦИАЛИЗАЦИЯ:
   - git config --global user.name "Имя" : Задает имя автора коммитов.
   - git config --global user.email "mail@ex.com" : Задает почту автора.
   - git init -b main : Создает новый локальный репозиторий с главной веткой main.

2. РАБОТА С ИЗМЕНЕНИЯМИ И КОММИТЫ:
   - git status : Показывает состояние файлов (отслеживаемые/неотслеживаемые, измененные).
   - git add . : Добавляет все изменения текущей папки в индекс (подготовка к коммиту).
   - git commit -m "Сообщение" : Фиксирует проиндексированные изменения, создавая точку сохранения.

3. ИСТОРИЯ И ИНСПЕКЦИЯ:
   - git log : Показывает полную историю коммитов (автор, дата, хеш, сообщение).
   - git log --oneline : Выводит компактную историю, где каждый коммит занимает одну строку.
   - git show [хеш] : Показывает детальные изменения (diff) в конкретном коммите.

4. УПРАВЛЕНИЕ ВЕТКАМИ:
   - git branch : Показывает список локальных веток. Текущая отмечена звездочкой (*).
   - git switch -c [имя_ветки] : Создает новую ветку и сразу переключает на нее.
   - git switch [имя_ветки] : Переключает на существующую ветку.
   - git branch -d [имя_ветки] : Безопасное удаление ветки (если изменения уже слиты).

5. УДАЛЕННЫЕ РЕПОЗИТОРИИ (GITFLIC / GITHUB):
   - git remote add origin [ссылка] : Связывает локальный репозиторий с удаленным.
   - git push -u origin [ветка] : Отправляет локальные коммиты на сервер и настраивает отслеживание.
   - git pull : Затягивает актуальные изменения с удаленного сервера в локальную ветку.
   - git fetch --prune : Обновляет информацию о ветках с сервера и чистит ссылки на удаленные ветки.
